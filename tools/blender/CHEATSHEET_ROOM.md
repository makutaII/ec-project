# Шпаргалка: комната из Blender в игру

Правила и обоснования: `ATTN_25_rooms.md` §25.7. Помощник: `tools/blender/ec_room_tools.py` (вкладка **EC Room** в боковой панели 3D-окна, клавиша **N**). Вагоны: `CHEATSHEET.md` и вкладка EC; панели можно держать включёнными вместе.

## Один раз
1. Scripting, Open, `tools/blender/ec_room_tools.py`, Run Script. Появилась вкладка EC Room справа.
2. Scene Properties, Units: Metric, **Unit Scale 0.01**, Length: Centimeters. **1 единица Blender = 1 см игры**: комната рисуется сразу числами игры (комната **480 × 380 × 250**, стол 200 × 100, пол на −50), как и вагоны (1 единица Blender = 1 единица игры). Масштаб при экспорте и импорте не меняется, `root_scale` не нужен. В 3D-окне поднимите View, Clip End (например до 5000), иначе дальние части комнаты обрежутся.
3. Исходник `.blend` лежит вне репозитория (например `E:\GodotCopy\Blender\Art\room_<имя>.blend`). Экспорт идёт в `data/models/room_<имя>/room_<имя>.glb`: папка в поле «Папка моделей», id берётся из имени `.blend` (поле «Id модели» его заменяет).

## Оси и ноль (запомнить)
- **Север (окно) это +Y Blender**, восток +X, верх +Z. Экспорт превращает +Y в −Z Godot, то есть в север игры.
- **Ноль по X и Y в центре комнаты** (там стоит стол 200 × 100). **Ноль по высоте на столешнице.** Пол на **−50**. Кнопка «Эталон: стол и пол» ставит рамки стола и пола (коллекция `EC_ref`, в экспорт не идёт) для сверки.
- Корень `Room` стоит в нуле мира, без поворота и масштаба.

## Что нарисовать (всё дети корня `Room`)
| Что | Объект | Роль (`role`) |
|---|---|---|
| корень | Empty `Room` | `room` (ровно один) |
| пол, стены с рамой и шторами, потолок | Empty-группы, меши внутри | `floor`, `shell`, `ceiling` |
| мебель, характер, мелочи | Empty-группы | `decor_t1`, `decor_t2`, `decor_t3` |
| ложный AO у стыков | Empty-группа | `fake_ao` |
| коллизия мебели | коробка | `collider` (сколько нужно) |
| окно, дверь | коробка по размеру проёма | `window`, `door` |
| границы камеры, объём комнаты | коробка | `camera_bounds`, `room_volume` (по одной) |
| центр стола, луч окна | Empty | `table_origin`, `window_sun` |
| лампа | Empty-якорь | `light` |
| колба, подвижная часть, небо | меш | `bulb`, `mech_part`, `sky_card` |

Обязательны: `room`, `floor`, `shell`, `camera_bounds`, `room_volume`. Остальное по необходимости. Одиночные роли у двух объектов это ERROR.

## Шаги
1. **Корень и группы**: Add, Empty, назвать, «Назначить из шаблона» (блок 1). Меши положить внутрь групп (Ctrl+P). Имена осмысленные: не `Cube`, без `.001` и пробелов.
2. **Меши**: мебель крупными кусками (кровать, шкаф отдельными объектами), мелкую статику внутри яруса объединить по материалам. Модификаторы применить. Только Principled BSDF.
3. **Прокси-коробки** (блок 2): выделить объекты, выбрать «Прокси» (`collider`, `window`…), «Прокси-коробка» ставит Wire-куб по их габариту. Без выделения коробка берётся из «Размер, см» в точке 3D-курсора. Коробка без поворота и материала, масштаб 1. Игра читает габарит и удаляет узел.
   - Окно: коробка во всю толщину стены, по размеру проёма; нужна северная (+Y) стена. Дверь: южная (−Y). Другие стены карточка не поддерживает.
   - `room_volume`: внутренний объём от пола до потолка (комната 480 × 380 × 250: 480 по X, 380 по Y, 250 по Z). `camera_bounds`: внутри него, низ выше столешницы (по умолчанию 3 над ней).
4. **Свет**: источников Blender не ставим (в экспорт не идут). Блок 1, «Свет»: вид, энергия Godot (100–250 для лампы на 120 см), дальность и угол в **сантиметрах и градусах**, цвет, тень (не больше 2 ламп с тенью). «Создать якорь света» ставит пустышку-стрелку в 3D-курсоре; **свет идёт по стрелке** (по умолчанию вниз; повернуть можно как угодно, Apply Rotation не нужен). Чтобы лампой управляли, перед созданием заполнить `ctl_id` (и подпись, «Где»).
5. **Колба**: меш лампочки с `emit_` материалом. Поле `bulb_of` = `ctl_id` лампы, «Колба: записать выделенным»: колба светится вместе с лампой.
6. **Управление** (блок 1, «Управление»): выделить объект, `Вид` (toggle, slider только для света, mech), `ctl_id` (snake_case, уникальный), подпись, «Где»: `Observe и студия` или `только Room Studio`, «Записать управление». Несколько ламп одним переключателем: общая `Группа`. Объект без `ctl` игрой не управляется.
7. **Механизм** (шторы, жалюзи, дверцы; блок 3): выделить подвижную часть (отдельный объект, origin на оси вращения для поворота), Id (`curtain`), «Ключ: покой» (кадр 1, имя `mech_curtain`, объекту сами пишутся `ctl = mech` и `ctl_id`). Сдвинуть или повернуть в рабочее положение, «Ключ: рабочее». Вернуть деталь в покой. Одно движение на деталь, масштаб не анимировать, интерполяция Linear ставится сама. Подпись и «Где» (Observe или студия): оставить деталь выделенной, в блоке «Управление» выбрать Вид mech, тот же `ctl_id`, «Записать управление».
8. **Применить трансформы** (блок 2): меши целиком; подвижные части и прокси только поворот и масштаб (Location сохраняет origin шарнира и центр коробки). Пустышки и объекты с детьми кнопка пропускает.
9. **Материалы** `<роль>_<имя>`: `paint_` (красится), `wood_`, `fabric_`, `metal_`, `plastic_`, `paper_`, `glass_` (прозрачное), `emit_` (светится). Не больше 24 штук. Текстуры вшиты, до 2048, не больше двух атласов. Вершинные цвета разрешены (ложный AO).
10. **Проверить комнату** (кнопка вверху): исправить все ERROR, WARN прочитать. Отчёт появляется в панели, **копируется в буфер обмена** (Ctrl+V в чат) и пишется в текст `EC_report`; галочка «Показывать INFO» добавляет числа карточки и список управления.
11. **Экспорт .glb** (блок 4): проверка, затем экспорт с нужными настройками (+Y Up, Custom Properties, без камер и Punctual Lights, без Draco, анимации Actions, вершинные цвета), затем `glb_preflight.py --kind room` по готовому файлу. При ERROR экспорт останавливается. Повторный экспорт идёт поверх старого файла.
12. **Числа в карточку**: из строки «Для карточки RoomConfig» отчёта (размеры, окно, дверь, границы, пол) и заготовок `MechanismConfig` (в RM8 карточка заполнится кнопкой «Обновить из сцены»).

## Проверка без Blender
```
python tools/glb_preflight.py data/models/room_<имя>/room_<имя>.glb --kind room
python tools/test_room_pipeline.py            # правила на эталоне и 34 поломках
```
Командный режим Blender: `blender -b art/blender/room_<имя>.blend -P tools/blender/ec_room_tools.py -- check` (код 1 при ERROR).

## Что чаще всего ломается
| Симптом | Причина |
|---|---|
| ERROR «нет объекта с role = …» | не назначена роль группе или прокси; роль стоит на данных меша, а не на объекте |
| комната в Godot в 100 раз меньше | нарисована в метрах (1 единица = 1 м): нужна 1 единица = 1 см. ERROR «не помещается» в проверке и Unit Scale не 0.01 |
| свет светит вверх или в стену | стрелка якоря смотрит не туда: свет идёт по стрелке |
| лампа не включается | нет `ctl` и `ctl_id`; колба: `bulb_of` не совпадает с `ctl_id` лампы |
| ERROR «mech_… без объекта» | у подвижной части нет `ctl = mech` и `ctl_id`, равного `<id>` действия |
| ERROR «и сдвиг, и поворот» | одна деталь двигается и сдвигом, и поворотом: разделите на две |
| ERROR про масштаб | Ctrl+A, Scale (или «Применить трансформы») |
| окно и дверь «не в той стене» | окно только в северной (+Y), дверь в южной (−Y) стене |
| штора «уехала» после экспорта | Apply Location на подвижной детали сбросил origin |
