# Свои образцы для кисти (Library, Model Studio, «Кисть»)

Каждая картинка в этой папке (png, jpg, webp) становится образцом в списке «Образец» режима «Кисть».
Файлы, имя которых начинается на `decal` (например `decal_01.png`), видны и как образцы (любой кистью, заливка текстурой), и как декали (инструмент «Декаль», один отпечаток или цепочка).
Название берётся из имени файла (`ржавые_подтёки.png` даёт «ржавые подтёки»). Список читается при входе в режим «Кисть»;
новый файл должен быть импортирован Godot (появиться в файловой системе редактора).

Требования к картинке:

- **Бесшовная**: левый край стыкуется с правым, верхний с нижним, иначе на модели видны полосы.
- **Цвет как есть**: краска берёт цвет образца, цвет из палитры не используется.
- **Альфа-канал это пятнистость**: где альфа 0, краска не ложится; без альфы образец сплошной.
- Размер любой, лучше квадрат 256-1024 пикселей. Повтор на модели задаёт ползунок «Размер образца» (доля габарита модели).
- Образец прикладывается по позиции на модели (triplanar), поэтому UV картинки на модели не важны.

Файлы, нужные только вам на этом компьютере, можно класть в `user://library/paint_samples` (в Godot: Проект, Открыть папку
данных проекта).
