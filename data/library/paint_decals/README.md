# Свои декали (Library, Model Studio, «Кисть», инструмент «Декаль»)

Каждая картинка в этой папке (png, jpg, webp) становится декалью в списке инструмента «Декаль».
Декалями считаются и файлы в соседней папке `data/library/paint_samples`, имя которых начинается на `decal` (например `decal_01.png`): их не нужно переносить, они остаются и образцами для кистей.
Название берётся из имени файла (`номер_12.png` даёт «номер 12»). Список читается при входе в режим «Кисть»;
новый файл должен быть импортирован Godot (появиться в файловой системе редактора).

Как это работает: клик ставит картинку на модель в касательной плоскости под курсором; галочка «Цепочка вдоль мазка» повторяет её вдоль мазка с шагом «Шаг, px», повернув по направлению мазка. Размер задаёт ползунок «Размер»
(это полуразмер большей стороны картинки), поворот «Поворот, °», «Зеркально» отражает слева направо, «Поток» это прозрачность.
Вверх по картинке это вверх по модели (ось Y).

Требования к картинке:

- **Форма задаётся альфа-каналом**: где альфа 0, краски нет. Для надписей и номеров нужна прозрачная подложка.
- **Цвет**: у своих картинок по умолчанию цвета самой картинки (галочка «Цвет из палитры» выключена). Если картинка белая
  или серая (шаблон), включите «Цвет из палитры»: она покрасится выбранным цветом.
- Размер любой, лучше 256-1024 по большей стороне (больше 512 уменьшается). Пропорции картинки сохраняются.
- Края лучше сглаженные (антиалиасинг), с запасом прозрачных пикселей по краям.

Файлы, нужные только вам на этом компьютере, можно класть в `user://library/paint_decals` (в Godot: Проект, Открыть папку
данных проекта).
